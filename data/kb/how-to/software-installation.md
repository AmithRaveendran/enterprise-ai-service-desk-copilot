# Installing Software from the Company Portal

Standard users do not have local administrator rights on company laptops. Approved software
is installed through the **Company Portal** app, without needing admin rights.

## Installing approved software

1. Open **Company Portal** from the Start menu (Windows) or Applications (macOS).
2. Browse or search the catalogue, for example "Visual Studio Code", "7-Zip" or "Zoom".
3. Click **Install**. Installation usually finishes within 15 minutes.

## Requesting software that is not in the catalogue

1. Raise a request in the Service Desk portal under **Software > New Software Request**.
2. Provide the software name, vendor, version, business justification and whether it
   needs a paid licence.
3. The request is reviewed by the Security team. Reviews take up to **10 business days**.
4. Paid software also requires a cost centre and manager approval.

Software is rejected if it is unsupported by the vendor, sends company data to unapproved
cloud services, or duplicates an approved tool. See the Software Installation Policy
(POL-0004) for the full rules.

## Temporary administrator access

Developers and IT staff can request **just-in-time admin access** through the Company Portal
app (**Request Admin Elevation**). Elevation lasts **60 minutes**, is logged, and requires a
reason. Repeated or unusual elevation requests are reviewed by Security.

## Licences

Licences for paid software (for example Adobe Acrobat Pro or Visio) are assigned to named
users. If you no longer need a licence, release it through **Software > Release Licence**
so it can be reassigned.

## Uninstalling software

Software installed from the Company Portal can be removed from the **Installed apps** tab.
Mandatory security tools (endpoint protection, SecureLink VPN, device management agent)
cannot be removed.

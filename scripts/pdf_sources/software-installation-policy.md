# Software Installation and Licensing Policy

## 1. Purpose

Unapproved software is one of the most common sources of malware, licensing breaches and data leaks. This policy explains which software may be installed on company devices and how new software is approved.

## 2. Rules

- Software may only be installed from the Company Portal catalogue, or by IT.
- Users must not install software from websites, browser extension stores or USB drives unless it appears in the Company Portal.
- Browser extensions are limited to the approved list published in the Company Portal. All other extensions are blocked automatically.
- Free or open-source software is subject to the same approval process as paid software. Free does not mean approved.
- Pirated, cracked or unlicensed software is strictly prohibited.

## 3. Approval process for new software

Requests are raised in the Service Desk portal under Software > New Software Request and must include the vendor, version, business justification and expected number of users. The Security team assesses each request against these criteria:

- Is the vendor reputable, and is the product actively supported and receiving security updates?
- Where is company data stored or processed, and does it meet the Information Security Policy (POL-0005)?
- Does it duplicate the features of a tool that is already approved?
- Does it require administrator rights or kernel drivers?

Assessments take up to 10 business days. Approved software is packaged and added to the Company Portal so that other users can install it too. Rejected requests receive a written reason and, where possible, an approved alternative.

## 4. Licensing

- Paid software is purchased centrally by End User Computing. Expense claims for software are not reimbursed.
- Licences are assigned to named users and are reclaimed automatically after 90 days without use.
- Users must release licences they no longer need through Software > Release Licence.

## 5. Administrator rights

Standard users do not have local administrator rights. Developers and IT staff may use just-in-time elevation through the Company Portal, which grants administrator rights for 60 minutes. All elevations are logged and reviewed by the Security team.

## 6. Non-compliance

Unapproved software found on a device is removed automatically by device management. Repeated breaches are reported to the user's manager and may lead to disciplinary action under the Acceptable Use Policy (POL-0001).
